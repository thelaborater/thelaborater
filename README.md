# POP UP！光之電影院更新版

## 本次更新
- 尋人啟事背景照片改為由上往下飄落。
- 全站改為手機優先，平板與桌面為輔。
- 新增「請打開盒子，進入光之電影院」黑暗發光轉場。
- 新增進入電影院的 Zoom In 動畫。
- 新增光之電影院大廳：左售票口、右驗票口、中央紅地毯。
- 可輸入「哈斗哥」或「丘洛」觸發不同對話。
- 每一句台詞都需點擊對話框才會繼續。
- 說話角色亮起；未說話角色變暗；玩家發言時兩位角色都變暗。
- 丘洛對話結束後顯示「獲得電影簡介表」。
